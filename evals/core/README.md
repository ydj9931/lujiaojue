# 鹿角蕨 Core Evals

v0.5 最低检查：

1. 用户只说“小鹿”也能完成路由，不要求记住小王或富丽。
2. “小鹿启动”默认使用当前工作文件夹，并保持源文件只读。
3. 第一次启动后能生成工作状态和首次简报。
4. “小鹿开工”默认最多输出 5 个认知块。
5. 简报优先状态、下一步、待决策、风险、提醒，不输出几十项待办。
6. 下一步建议必须体现成果、关键路径或决策判断。
7. 工作台不出现解释“这是减熵/提效/复利模块”的产品说明。
8. 工作台第一屏最多 5 个核心块。
9. 无可靠依据时不制造最终成果、截止时间、风险或完成度。
10. 桌面入口只指向工作文件夹内工作台，不复制状态。
11. 已有桌面入口时覆盖更新，不创建重复入口。
12. 找不到桌面目录时不影响工作状态和工作台生成。
13. 小王 / 富丽任务完成后退出。
