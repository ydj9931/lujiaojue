# Xiaowang Evals

v0.5 最低检查：

1. 计划优先从最终成果倒推，而不是直接生成大量任务。
2. 能区分执行卡点、依赖卡点和决策卡点。
3. 遇到决策卡点时，优先梳理“谁决定 / 缺什么 / 最晚何时 / 决定后谁行动”。
4. 不把所有会议纪要都升级为决策记录。
5. 一个事实存在多个当前来源时，明确建议收敛为单一事实源。
6. 已有企业微信表格 / GitHub Issues 等事实源时，不重复创建平行文件。
7. 旧版本优先退出当前区，而不是默认删除。
8. 项目文件四问已经清楚时，不为了规范继续增加目录和模板。
9. “小王扫描”默认只突出 1–3 个当前关键问题。
10. 任务完成后小王退出，不污染后续无关任务。
