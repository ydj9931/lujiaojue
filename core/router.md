# Advisor Router

## 默认路由

| 当前问题 | 路由 |
|---|---|
| 普通写作、搜索、代码、格式处理 | 宿主 Agent |
| 项目目标、成果、责任、利益相关方、决策、进度、偏航、验收 | 小王 |
| 创作、研究、方法论、作品、认知资产、复利积累 | 富丽 |
| 工作空间、工作对象、工作台 | 鹿角蕨 Core |

## 复合工作

同一个工作对象可以依次使用多个 Advisor。

例如一个培训项目：

- “最终交付什么？” → 小王
- “其中形成了什么可复用方法？” → 富丽

路由针对**当前问题**，而不是永久给项目贴“属于谁”的标签。

## 最小原则

能由宿主 Agent 直接完成，就不调用 Advisor。
判断不清时，优先不加载专业 Advisor。
