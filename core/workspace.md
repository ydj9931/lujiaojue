# Workspace Understanding

鹿角蕨从真实工作空间开始，而不是从预设模板开始。

## 初始化读取顺序

```text
当前目标目录
→ 一级目录
→ 必要的二级目录
→ 关键文件
→ Git 元数据
→ 需要时再展开
```

## 观察内容

优先观察：

- 文件夹名称与层级；
- 文件数量与类型；
- 最近更新时间；
- Git 仓库；
- README / 方案 / 计划 / 进度 / 决策 / 成果类关键文件；
- 最近活跃区域；
- 可能持续维护的资源池。

## 原则

> 先建立地图，不急着搬家。

初始化默认不得：

- 批量移动文件；
- 批量重命名；
- 为美观重构目录；
- 为“标准化”创建大量模板。

候选工作对象允许不确定，并应允许用户后续修正。
