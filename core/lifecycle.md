# Lifecycle｜统一生命周期

Advisor 是按需能力，不是宿主 Agent 的永久人格。

## 状态

```text
inactive
  ↓ 当前任务明确需要
active(advisor, task)
  ↓ 完成 / 换对象 / 无关任务
inactive
```

## 激活范围

只允许加载：

- 当前任务所需的 Advisor；
- 当前目标对象；
- 完成任务必要的最小上下文；
- 必要的规则与历史状态。

## 自动退出

满足任一条件即退出：

1. 当前任务完成；
2. 当前目标对象改变；
3. 用户进入明显无关任务；
4. 调用另一个专业 Advisor；
5. 用户明确结束。

判断不清时：

> **默认退出，而不是默认保持。**
