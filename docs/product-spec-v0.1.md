# 鹿角蕨 v0.1 产品方案

> **从你的工作里，长出你的工作台。**

## 定位

鹿角蕨（Lujiaojue）是一套运行在超级 Agent 之上的生成式工作台。

核心路径：

```text
真实工作
→ 工作空间感知
→ 识别工作对象
→ 生成工作台
→ 按需调用 Advisor
→ 持续修正和生长
```

## 三层架构

```text
超级 Agent
  ↓
鹿角蕨 Core
  ↓
工作空间 / 工作台
  ↓
专业 Advisor
├── 富丽：复利创作
└── 小王：项目推进
```

## Core 职责

只处理真正公共的问题：

- Workspace Understanding
- Work Object
- Advisor Router
- Lifecycle
- Workbench

根 `SKILL.md` 是 Router，不是 Super Advisor。

## Advisor

### 富丽

发现工作中值得复利的东西。

关注创作、研究、方法、Workflow、作品、长期认知资产。

### 小王

让项目向成果闭环收敛。

关注目标、需求、成果、利益相关方、责任、决策、节点、进度、偏航、验收。

## 复合型工作

工作对象不永久属于某个 Advisor。

路由针对当前问题：

```text
“这个项目最后交付什么？” → 小王
“这里有什么值得沉淀？” → 富丽
```

## Advisor First

专业能力优先留在所属 Advisor。

只有已经被证明是稳定的跨 Advisor 公共能力，才上移 `core/`。

## 初始化

入口：

```text
鹿角蕨初始化
```

第一原则：

> **先建立地图，不急着搬家。**

默认不移动、不批量重命名、不为了标准化制造大量目录。

## 工作台

v0.1 只回答：

- 我最近在做什么？
- 什么发生了变化？
- 什么值得我关注？

不是任务管理器。

## v0.1 最小范围

```text
工作空间感知
+
工作对象识别
+
生成工作台
+
Advisor 路由
```

不做独立 App、大型知识库、复杂多 Agent 编排和 Advisor 常驻。
