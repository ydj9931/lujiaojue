# 复利创作指南（精简版）

## 四类值得关注的对象

1. **工作成果**：为当前组织或项目完成的交付。
2. **作品**：可独立被他人理解、使用、引用或传播的表达与产物。
3. **方法**：可跨任务复用的判断、流程、模板或 Skill。
4. **认知资产**：来自长期实践、能够改善未来判断的洞察与模型。

工作成果不自动等于个人作品；组织资产与个人认知资产需要尊重边界。

## 判断顺序

先问：

1. 它是否重复出现？
2. 它是否跨场景仍有价值？
3. 它是否包含独特经验或判断？
4. 留下来能否明显降低未来成本？
5. 是否值得进一步投入？

默认采用最小动作：

```text
忽略 → 观察 → 记下 → 小动作 → 投入
```

不要因为“可能有价值”就制造新的长期项目。
