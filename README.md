# 鹿角蕨 Lujiaojue

> **从你的工作里，长出你的工作台。**

鹿角蕨运行在 WorkBuddy、Codex、Claude Code 等能够操作本地文件的超级 Agent 中。

用户只需要记住一个名字：

# **小鹿**

第一次：

```text
小鹿启动
```

以后：

```text
小鹿，……
```

小王和富丽是小鹿内部调用的专业能力，不是用户必须学习的入口。

---

## 鹿角蕨做什么

```text
先减熵
→ 再提效
→ 把事情做成
→ 让价值继续生长
```

做事方式：

> **灵魂是顾问，落实是助理。**

表达方式：

> **价值先于解释。**

界面原则：

> **复杂性留给 Agent，清晰留给人。**

## 安装

你需要先有一个能够读取和操作本地文件的超级 Agent。

### Claude Code

本仓库可以直接作为 Plugin 使用。

本地测试：

```bash
claude --plugin-dir ./lujiaojue
```

### Codex

把仓库地址交给 Codex：

```text
请从 https://github.com/ydj9931/lujiaojue 安装鹿角蕨，
并将 skills/lujiaojue、skills/fuli、skills/xiaowang
安装为全局可复用 Skills。
优先使用你原生的 Skill / Plugin 安装机制。
安装后验证三个 Skill 都可以被发现。
```

### WorkBuddy

把仓库地址交给 WorkBuddy：

```text
请从 https://github.com/ydj9931/lujiaojue 安装鹿角蕨，
并同时安装鹿角蕨、富丽和小王三个 Skills。
推荐全局安装。
```

## 第一次使用

用 Agent 打开一个你平时真正工作的文件夹，然后说：

```text
小鹿启动
```

小鹿会：

```text
理解这里正在做什么
→ 找出主要工作
→ 找到当前事实和明显混乱
→ 建立工作状态
→ 给出第一次工作简报
→ 创建桌面「小鹿工作台」入口
```

开始前会说明：

> 我会先看看这个文件夹里你正在做哪些工作，不会移动或修改你的源文件。

第一次默认只读。

---

## 每天怎么用

每天第一次进入工作文件夹，小鹿优先做一件事：

> **先汇报，再建议。**

开工简报最多只保留 5 个认知块：

```text
现在到哪了？
今天最该推进什么？
有什么在等决定？
什么可能出问题？
有什么需要整理或提醒？
```

不把几十个任务等权展示。

---

## 小鹿工作台

工作台不是鹿角蕨本体，只是一个全局视图。

第一次启动后，小鹿默认在桌面创建：

```text
小鹿工作台
```

入口只指向当前工作状态，不复制事实源。

需要全局看一眼时：

```text
小鹿，打开工作台
```

工作台只直接呈现价值：

```text
最终成果
关键时间
当前最重要
待决策
最大风险
```

解释性内容默认不出现。

## 小王与富丽

用户可以一直只找小鹿。

小鹿会根据问题自动调用：

```text
项目成果 / 决策 / 推进
→ 小王

创作 / 沉淀 / 复利
→ 富丽
```

熟悉后也可以直接使用：

```text
小王扫描
小王整理
富丽扫描
```

但它们只是高级快捷入口。

### 小王

> **把事情做成。**

核心方法：

```text
成果倒推
→ 决策开路
→ 关键路径推进
→ 闭环验证
```

项目文件指南：

[`工作成果项目文档整理指南`](skills/xiaowang/doctrines/project-file-guide.md)

### 富丽

> **把做成以后值得留下的东西继续养大。**

富丽负责创作、长期资产、方法、作品、发布和复利判断。

创作文档指南：

[`复利创作文档整理指南`](skills/fuli/references/creative-document-guide.md)

## 鹿角蕨的五条工作原则

### 1. 先减熵，再增益
不继续制造无意义复杂度。

### 2. 灵魂是顾问，落实是助理
先判断真正问题，再利用 Agent 把正确判断落实到文件和行动。

### 3. 价值先于解释
不解释产品能力，直接呈现它已经发现、减少、推进和形成了什么。

### 4. 认知负载优先
面向人的一个核心视图原则上只承载 4–5 个认知块。

### 5. 每天先看清局面，再开始工作
先汇报当前状态、下一步建议、决策、风险和提醒。
