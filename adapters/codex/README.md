# Codex / OpenAI Skills

鹿角蕨使用标准 `SKILL.md + 支持资源` 目录结构。

推荐由 Codex 自己执行安装，而不是要求普通用户手工复制目录。

可以直接告诉 Codex：

```text
请从 https://github.com/ydj9931/lujiaojue 安装以下三个 Skills 为全局可复用能力：
- skills/lujiaojue
- skills/fuli
- skills/xiaowang

优先使用你原生的 Skill / Plugin 安装机制。
安装后验证三个 Skill 都能被发现。
```

如果当前产品提供 Plugin / Skills UI，也可通过 UI 安装或上传。

不要在这里固定一个未经宿主官方支持的私有目录结构；以宿主当前原生安装器为准。
