# WorkBuddy

WorkBuddy 以 Skills 作为可安装能力单元。

推荐方式：

1. 打开 WorkBuddy；
2. 使用技能（Skills）入口；
3. 从 Marketplace 安装，或让 WorkBuddy 从本仓库创建 / 导入自定义 Skill；
4. 推荐全局安装；
5. 同时加载鹿角蕨、富丽、小王。

可以直接告诉 WorkBuddy：

```text
请从 https://github.com/ydj9931/lujiaojue 安装鹿角蕨。
把它作为全局可复用 Skill 使用，并同时安装：
- skills/lujiaojue
- skills/fuli
- skills/xiaowang

安装后在一个新的任务中验证“鹿角蕨初始化”。
```

适配层不重复实现富丽或小王逻辑。
